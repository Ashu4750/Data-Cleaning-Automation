# Data Cleaning and Reporting Automation

## Project Description
This project focuses on cleaning and preprocessing animal observation data using Python.

## Objectives
- Handle missing values
- Remove duplicate records
- Standardize inconsistent data
- Validate the cleaned dataset
- Generate automated reports
- Create visual summaries

## Files Included
- Original_Animal_Data.csv – Original dataset
- Data_Cleaning_Automation.ipynb – Python data cleaning and reporting process
- Cleaned_Animal_Data.csv – Final cleaned dataset
- Data_Cleaning_Report.xlsx – Excel report containing cleaned data and summaries

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Excel
- Google Colab
